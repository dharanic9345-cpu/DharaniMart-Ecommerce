# DharaniMart

Native C++20 multi-seller e-commerce marketplace.

## Required technology
- C++20
- Drogon Framework
- PostgreSQL / SQLite
- CMake
- vcpkg
- HTML
- CSS
- JavaScript
- GitHub

## Mandatory modules
1. User Registration & Login
2. Seller Product Management
3. Buyer Shopping
4. Cart
5. Checkout
6. Order History
7. Admin Panel
8. Product Reviews & Ratings

## Later phase
- Wishlist
- Order Tracking
- Seller Sales Dashboard
- AI Chatbot

## Current starter milestone
CMake + vcpkg + Drogon project structure and a basic health endpoint.

No index.html is included because the college specification requires HTML/CSS/JavaScript as frontend technologies, but does not specifically require a file named index.html.
